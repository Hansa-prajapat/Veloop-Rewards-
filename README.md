# VELOOP Rewards — Watch Ads (Complete)

Original React + Vite implementation based on the public feature requirements of the referenced VELOOP Watch Ads project. It includes a complete interactive Watch Ads flow: loading, countdown, progress, completion, reward success, already-watched and no-ads states, six unique ads, rewards, durations, daily/lifetime earnings, recent activity, daily bonus, responsive navigation and localStorage persistence.

## Run
npm install
npm run dev

## Build
npm run build
npm run preview

## GitHub
Upload the project root. Do not upload `node_modules`; run `npm install` after cloning.
